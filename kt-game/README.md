# 战锤 40,000：杀戮小队 · 电子战术版 (`kt-game/`)

基于仓库内 Android 辅助应用的完整中文数据库与高清卡图资产构建的 **独立电子桌游原型（Godot 4 + GDScript）**。  
本目录完全独立于根目录 Android 工程，**对原有辅助应用代码与目录结构零侵入、零修改**。

---

## 🚀 一键启动试玩

在仓库根目录或 `kt-game/` 目录下直接运行：

```bash
./kt-game/run.sh
```

> 也可以直接打开 `/Applications/Godot.app`，导入 `kt-game/project.godot` 后按 **F5** 运行或编辑。

## 🎮 原型核心特性（UI & 用户体验优先）

1. **官方地图 + 真实地形 + 3D 涂装棋子（杀戮区：沃库斯 `30" × 22"`）**
   - 内置 **认证行动 2025 全部六张官方地图**（`data/maps/volkus_25_01.json` … `volkus_25_06.json`），默认地图 4；**开局界面可以选择地图 1–6**，也可用命令行参数 `--map=volkus_25_02` 指定。由 `tools/build_volkus_map.py` 从 TTS 模组的官方布局 JSON 与地形 OBJ 生成：每个地形件按高度带切成规则矩形（底层墙体 heavy / 二层楼板 vantage / 墙垛 light），坐标与朝向约定经六张官方地图图片数值拟合校验。降落区按规则书：地图 1–3 为东/西两侧短边 6" 纵深，地图 4–6 为南/北两侧长边 3" 纵深；默认落点由工具自动生成并避开所有地形。
   - 场上渲染的是 **堡垒、大型/小型废墟的真实 3D 模型**（`assets/terrain/volkus/`，含贴图）和 **官方沃库斯底垫**；1" 格 / 6" 铜线 / 部署区仍以半透明叠层画在底垫上（⚙ 可关）。
   - 棋子默认为 **3D 涂装模型**（`assets/minis/`，16 个特工，几何与贴图取自 TTS 模组，规则文字一律不取），⚙ 可切换为 **亚克力立牌 token**（阵营边框 + 官方卡图胸像）。受击后仰、阵亡翻倒并留下骷髅标记。
   - 可见性按 **3D 判定**（规则 p.29）：眼高 1.4"、模型高 1.6"，重型地形按实际高度挡视线，轻型不挡，脚下制高点楼板不挡。
   - 棋子头顶默认只显示命令图标 + 血条，悬停 / 选中才展开完整名牌；只停靠当前行动方的花名册。
   - 堡垒/废墟二层楼板与踏台为制高点（踏台按规则书为制高点、不重要、暴露地形），3 座目标点实时显示 `1"` 控制范围光环与双方 APL 对比。
2. **连续英寸几何量尺 & 落点视线预瞄**
   - 点击【转移 / 冲刺 / 冲锋 / 后撤】后，鼠标实时绘制带 `1"` 刻度的英寸量尺，自动计算攀爬二层露台（`+2"`）与敌方 `1"` 控制范围阻挡。
   - 按住 **Shift + 左键** 可添加多个折线拐点绕过重型废墟墙体；落脚绿圈会实时向全场敌军投射虚线，提前预判移动后能打到谁！
3. **自动视线（LoS）& 外公切线掩护锥（Cover Cone）**
   - 射击模式下每名敌军底座显示颜色环：**翠绿 = 暴露无掩护**、**亮金 = 享有掩护**、**暗紫 = 重型遮挡（Obscured）**、**灰 = 不可选**；只有悬停目标才绘出激光视线、掩护锥与命中预测卡，避免全场拉线。
   - 移动模式显示阵营色**可达范围盘**（含 2" 刻度环），量尺与 Shift 拐点照旧。
   - 击杀触发 0.9 秒慢放 + 推镜；阶段切换为全宽横扫横幅；战略计谋以带阵营水印的卡面发牌。音效来自 Kenney CC0 包（`assets/audio/LICENSE.md`），另有低音量环境音循环。
4. **规则词典与技能效果可视化**
   - `data/core/glossary.json`（由 `tools/build_glossary.py` 生成，81 条）：武器规则、状态、阵营规则、特工能力、计谋、战团战术、装备，每条一句话效果 + 规则原文。
   - 界面上任何规则名都是**可查词条**（`KTRuleChip`）：武器卡关键词、技能提示框、英雄面板能力行、战斗面板修正标签。悬停看一句话，点击展开原文。
   - 掷骰结算改为**规则时间线**：每条触发的规则按顺序逐行出现（默认停 0.3 秒，⚙ 设置可调 / 关闭），对应骰子抬起变色并显示徽章。
5. **桌面沉浸（路线 B）**
   - CP 以黄铜筹码堆、VP 以轨道标记、TP 以木块、当前激活特工的数据卡以卡垫形式**实体摆在右侧桌沿**（`KTTableProps3D`），B 方镜像到对侧。顶栏只保留数字速览。
   - 底部英雄面板与技能栏合成一块控制台，武器卡抽屉从射击槽上方弹出；右上系统栏为图标按钮，含 ⚙ 设置（规则停顿 / 击杀慢放 / 英寸格线，存于 `user://settings.cfg`）。
6. **全自动阵营规则 & 交互式攻防骰盘**
   - 完整实现 **死亡天使（IMP-AOD）vs 瘟疫战士（CHAOS-PM）** 经典对决：8 项战前战团战术自由两两组合、阿斯塔特双射/双战与跨命令反应（Counteract）、纳垢毒素、恼人韧性 `4+` 减伤、钢铁光环、纯洁印章、狙击手瞄准镜、恶瘟投放者灵能等。
   - 右侧停靠式骰盘（不遮挡左侧战场），支持点击单骰执行【平衡 / 指挥重掷 (1CP) / 无休 / 不懈】，也支持 **⚡ 一键快速结算**；近战支持双方逐骰交替【出击 / 格挡】博弈。
7. **单人迎战战术 AI & 双人同屏热座 + 无限步撤回 + 官方原卡灯箱**
   - 开局自由切换 **🤖 单人迎战电脑 AI**（可自由选择执掌帝国或纳垢）与 **👥 本地双人同屏热座**。
   - 随时点击任意特工旁的【卡】或顶栏【帝国卡册 / 纳垢卡册】调阅官方高清中文数据卡与计谋卡；任何误操作可随时点击顶栏 **↶ 撤回**。

8. **完整战前流程（规则 p.105–107）**
   - 战前拼骰 → 选降落区（对手获得重投先手权卡）→ 秘密选出战特工 → 秘密选装备（阵营装备 + 通用装备，最多 4 项）→ 秘密选战术行动 op → 轮流部署战前装备（轻型掩体 / 重型掩体 / 地雷）→ 轮流按三分之一部署特工。
   - 每个转折点先手权拼骰后进入先手权卡步骤（重投 / ±1 / ±2 / ±3）；TP1 作为战略计划秘密选择主要行动 op；击杀行动按击杀等级表计分；已实装战术行动：主宰、殉道者、特使、击溃。
   - 尚未实装：通用装备中的弹药储备、铁丝网、通讯装置、爬梯、可移动掩体、功能型手雷，以及其余 8 张战术行动卡（界面中置灰）。

## 🛠️ 开发与常用命令

```bash
# 重新从 ../app 同步首发双阵营高清卡图与圆形头像（只读读取 ../app）
python3 kt-game/tools/sync_assets.py

# 一次性同步全部 48 支杀戮小队 JSON 与卡图（为后续全阵营扩展准备）
python3 kt-game/tools/sync_assets.py --all

# 运行无头核心几何/战斗规则/AI 自动化单元测试（当前 114 项断言）
/opt/homebrew/bin/godot --headless --path kt-game -s res://tests/run_all.gd

# 自动生成 13 张全流程 UI 视觉验收截图（输出至 kt-game/build/screenshots/）
/opt/homebrew/bin/godot --path kt-game -- --autotest-screenshots

# 指定地图跑同一套截图巡检
/opt/homebrew/bin/godot --path kt-game -- --autotest-screenshots --map=volkus_25_02

# 从 external-assets 的 TTS 布局重新生成六张官方地图（加 -v 输出规则矩形明细）
python3 kt-game/tools/build_volkus_map.py all
```

## 📂 目录结构

```text
kt-game/
├── project.godot               # Godot 4 工程配置 (1600x960 自适应高分屏)
├── run.sh                      # 一键资源检测与启动脚本
├── tools/sync_assets.py        # 从 ../app 只读提取 JSON/卡图/圆形头像并生成亚克力立牌 token 的资源管线
├── tools/build_volkus_map.py   # 从 external-assets 的 TTS 布局 JSON + 地形 OBJ 生成 data/maps/*.json
├── tools/build_glossary.py     # 生成 data/core/glossary.json 规则词典
├── data/maps/                  # 六张官方地图数据（规则矩形 + 模型摆放 + 降落区 + 默认落点）
├── assets/terrain/volkus/      # 沃库斯地形 3D 模型与官方底垫（取自 TTS 模组，仅几何/贴图）
├── assets/minis/               # 16 个特工的 3D 涂装棋子（manifest.json 记录底座尺寸与朝向）
├── assets/textures/            # ambientCG CC0 PBR 贴图（LICENSE.md 记录来源）
├── assets/audio/               # Kenney CC0 音效与环境音（LICENSE.md 记录来源；dice_roll 由 ../app 同步）
├── data/
│   ├── core/core_rules.json    # 核心阶段与通用规则配置
│   └── teams/                  # 结构化阵营与武器词条 JSON (IMP-AOD, CHAOS-PM)
├── scenes/Main.tscn            # 游戏主场景入口
├── src/
│   ├── core/
│   │   ├── kt_data.gd          # 阵营数据、战团战术目录与沃库斯杀戮区地图定义
│   │   ├── kt_geometry.gd      # 连续英寸几何碰撞、攀爬折算与外公切线视线/掩护求解器
│   │   ├── kt_combat.gd        # 远程射击与近战交替出击/格挡引擎（含审计报告规则修复）
│   │   ├── kt_engine.gd        # TP1-TP4 状态机、战略/交战计谋、目标占领计分与撤回栈
│   │   └── kt_ai.gd            # 单人战术 AI 决策器
│   ├── board/
│   │   ├── killzone_view.gd    # 3D 战场渲染器、英寸量尺、掩护锥、相机控制、击杀慢放与棋子动画
│   │   ├── kt_models_3d.gd     # 贴图地形 / 底座 / 亚克力立牌 token 工厂
│   │   ├── kt_vfx_3d.gd        # 粒子与战斗特效
│   │   └── kt_dice_3d.gd       # 桌面 3D 骰盒与翻滚 D6
│   └── ui/
│       ├── kt_theme.gd         # 暗黑哥特战术鸟卜仪主题与跨平台中文字体回退链
│       ├── main_game.gd        # 全局 HUD、出战配置页、双小队花名册与行动控制台
│       ├── dice_combat_modal.gd# 右侧停靠式交互攻防骰盘
│       └── card_lightbox.gd    # 官方高清中文数据卡/规则书灯箱
└── tests/run_all.gd            # 无头几何与规则单元测试套件（114 项断言）
```
