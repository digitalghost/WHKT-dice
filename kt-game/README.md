# 战锤 40,000：杀戮小队 · 电子战术版 (`kt-game/`)

基于仓库内 Android 辅助应用的完整中文数据库与高清卡图资产构建的 **独立电子桌游原型（Godot 4 + GDScript）**。  
本目录完全独立于根目录 Android 工程，**对原有辅助应用代码与目录结构零侵入、零修改**。

---

## 🚀 一键启动试玩

在仓库根目录或 `kt-game/` 目录下直接运行：

```bash
./kt-game/run.sh
```

> 也可以直接打开 `/Applications/Godot.app`，导入 `kt-game/project.godot` 后按 **F5** 运行或编辑。

## 🎮 核心特性与规则实现

1. **官方地图 + 真实 3D 地形与涂装棋子（杀戮区：沃库斯 `30" × 22"`）**
   - 内置 **认证行动 2025 全部六张官方地图**（`data/maps/volkus_25_01.json` … `volkus_25_06.json`），默认地图 4；**开局界面可直接选择地图 1–6**，也支持命令行 `--map=volkus_25_02`。由 `tools/build_volkus_map.py` 从官方布局与地形 OBJ 生成并校验目标点与墙体无重叠。降落区严格按规则书：地图 1–3 为东/西短边 `6"` 纵深，地图 4–6 为南/北长边 `3"` 纵深。
   - 场上渲染 **堡垒、大型/小型废墟的真实 3D 模型**（`assets/terrain/volkus/`）与官方沃库斯底垫，叠加半透明 `1"` 格线 / `6"` 铜线 / 降落区（⚙ 可切换）。
   - 棋子默认采用 **16 个特工 3D 涂装模型**（`assets/minis/`），⚙ 可切换为 **亚克力立牌 token**；受击后仰、阵亡翻倒并留下阵营骷髅标记，支持 3D 撤回同步还原。
   - 可见性与范围判定全面采用 **3D 垂直距离**（规则 p.22 / p.29）：包含可见性、控制范围、飞蝇云、传染、排毒口、监控/追踪敌军、震荡手雷与近战支援；重型地形按实际高度阻挡视线，制高点楼板与踏台按规则书处理。

2. **连续英寸几何量尺、分段折算与落点视线预瞄**
   - 移动模式（转移 / 冲刺 / 冲锋 / 后撤 / 与掩体移动）实时绘制带 `1"` 刻度英寸量尺与可达范围盘；严格按核心规则实现 **每段路径独立向上取整**、**攀爬按高度向上取整**、**跳落忽略前 `2"`**、**冲刺禁止攀爬**、**反击总移动上限 `2"`**、**重型武器移动限制** 与 **铁丝网/爬梯** 地形修正。
   - 按住 **Shift + 左键** 可添加多个折线拐点绕过重型废墟墙体；落脚绿圈实时向全场敌军投射预瞄虚线。

3. **自动视线（LoS）、外公切线掩护锥与完整 9 步射击管线**
   - 射击模式按底座光环区分目标状态：**翠绿 = 暴露无掩护**、**亮金 = 享有掩护**、**暗紫 = 重型遮挡（Obscured）**、**灰 = 不可选**；悬停时显示 3D 激光视线、外公切线掩护锥与命中预测。
   - 完整实现 **爆炸（Blast）/ 洪流（Torrent）多目标链式结算**（支持洪流提前终止次要目标，且多目标行动末尾仅掷一次 **过热 Hot** 检定并联动慈父赐福）。
   - 完整实现 **精准 / 平衡 / 无休 / 毁灭 / 致命 / 穿刺 / 关键穿刺 / 毒素 / 重击 / 撕裂 / 饱和 / 寻轻 / 严重 / 静默 / 晕眩 / 剧毒 / 过热** 等核心武器词条，严格区分自然命中与保底转化骰（防止重击链入撕裂），并支持 **制高点/隐匿掩护 `2普 ↔ 1暴` 切换** 与 **狙击手迷彩斗篷 + 隐匿双掩护（`1暴 + 1普`）**。

4. **近战交替出击/格挡博弈与阵营完整机制**
   - 完整支持 **死亡天使（IMP-AOD）vs 瘟疫战士（CHAOS-PM）**（共 16 名特工原型）：
     - **死亡天使**：8 项战团战术自由两两组合、阿斯塔特双射/双战与跨命令反击（Counteract）、3 种战斗条令、他们无所畏惧、不屈不挠、超人体格、震慑突袭、复仇之怒、纯洁印章、战团圣物（0CP 复仇之怒）、偏移肩盾（按 2026 勘误掷骰后按需触发）、占卜仪、钢铁光环、狙击手瞄准镜。
     - **瘟疫战士**：纳垢毒素、恼人韧性 `4+` 减伤、传染、慢步死亡、飞蝇云、纳垢灵、致命毒素、恶心韧性、腐烂诅咒（攻/防骰锁死 `3` 点且不可重掷/不可保留）、瘟疫之钟、疫病手雷、瘟疫弹药、排毒口、腐蚀连枷横扫、有毒瘴气、腐烂活力、慈父赐福。
   - 近战支持逐骰交替 **出击 / 格挡**，含 **暴击优先格挡普通成功**、**对手 0 成功骰空格挡**（p.18）、**残暴限制**、**决斗家普挡暴**、**震荡** 与 **暴击保留即触发晕眩**。
   - 阵营卡库覆盖 **21 / 24** 张核心策略与装备卡实战交互；剩余 3 张边缘策略卡（`灵活战术`、`调整条令`、`剧毒破灭`）及军士单体额外战术「战团老兵」可在原卡灯箱中查阅原文，暂未开放独立交互按钮。

5. **完整战前流程、11 项通用装备与 12 张战术行动（规则 p.105–107）**
   - 完整流程：`战前拼骰 → 选降落区（含互换与重投先手权卡）→ 秘密选特工 → 秘密选装备（最多 4 项）→ 秘密选战术行动 → 轮流部署装备（可旋转 90° 或跳过，0 装备自动跳过）→ 按三分之一轮流部署特工 → TP1–TP4（先手权卡 ±1/±2/±3/重投 → 战略阶段与 TP1 主任务 → 交战阶段）→ 终局结算`。
   - **11 项通用装备全部可选**：弹药储备（0AP 补充弹药）、铁丝网、通讯装置、地雷（触发 `D3+3`）、轻型掩体、重型掩体、爬梯、可移动掩体（含保护豁免+1 与「与掩体移动 1AP」）、功能型手雷（烟雾/震荡自由配比，烟雾含跨回合 D3 消散与穿刺 2→1 减免）、爆破型手雷（破片/穿甲自由配比）、破拆炸药。（注：两支小队无「支援」规则且沃库斯无突破点，通讯装置与破拆炸药可合法选装/部署但无额外触发效果。）
   - **12 张战术行动全部实装并接入桌面标记与结算**：侧翼、插旗、主宰、放置装置、回收、殉道者、扫荡清理、追踪敌军、敌情、特使、击溃、窃取情报（每队按原型可选 6 张）。

6. **桌面沉浸体验、规则词典、单人 AI / 热座与全阶段撤回**
   - **实体桌面配件**（`KTTableProps3D`）：CP 铜筹码堆、VP 轨道、TP 木块、当前特工数据卡垫实体摆放在桌沿；击杀慢放推镜、阶段横幅、Kenney CC0 音效与环境音（接入 `KTSettings` 音量配置）。
   - **可查规则词典**（`glossary.json` 84 条 + `KTRuleChip` / `KTRulePopover`）：界面中所有关键词悬停看简述、点击固定看规则原文，按 `ESC` 干净关闭不穿透底层操作。
   - **单人 AI + 双人热座 + 无限步撤回**：支持单人执掌帝国/纳垢对抗战术 AI（含拐角绕墙与连枷调度）或双人同屏热座（附秘密选择隐私幕布）；`↶ 撤回` / `Z` 键支持全 9 阶段与交战骰盘内直接回退并逐字节还原状态。
   - **常用快捷键**：`Space`（确认/推进阶段/主按钮）、`Z`（撤回）、`R`（装备部署旋转 90°）、`F`（重置等距视角）、`Tab`（当前特工数据卡）、`C`（激活前切换命令）、`F1 / F2`（帝国/纳垢规则原卡库）、`ESC`（取消当前交互或关闭弹窗）。

## 🛠️ 开发与常用命令

```bash
# 重新从 ../app 同步首发双阵营高清卡图与圆形头像（只读读取 ../app）
python3 kt-game/tools/sync_assets.py

# 一次性同步全部 48 支杀戮小队 JSON 与卡图（为后续全阵营扩展准备）
python3 kt-game/tools/sync_assets.py --all

# 运行无头核心几何/战斗规则/AI/UI 自动化单元测试（326 项断言）
/opt/homebrew/bin/godot --headless --path kt-game -s res://tests/run_all.gd

# 全程对局测试：AI 驱动双方在六张地图上从战前打到终局并逐步检查状态（报告在 build/playtest/report.md）
/opt/homebrew/bin/godot --headless --path kt-game -s res://tests/scenario_playtest.gd -- --seeds=20
# 加 --all-tacs 可让 12 张战术行动卡都被选到

# 实盘 3D GUI 端到端自动对局验收（支持指定地图、模式与执掌方）
/opt/homebrew/bin/godot --headless --path kt-game res://scenes/Main.tscn -- --playtest-ui --map=volkus_25_02 --mode=ai --side=A

# 自动生成 13 张全流程 UI 视觉验收截图（输出至 kt-game/build/screenshots/）
/opt/homebrew/bin/godot --path kt-game -- --autotest-screenshots

# 指定地图跑同一套截图巡检
/opt/homebrew/bin/godot --path kt-game -- --autotest-screenshots --map=volkus_25_02

# 从 external-assets 的 TTS 布局重新生成六张官方地图（加 -v 输出规则矩形明细）
python3 kt-game/tools/build_volkus_map.py all
```

## 📂 目录结构

