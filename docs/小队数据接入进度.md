## 5. 已知的通用问题（下批注意）

- 骨架会漏：换行后的武器规则、无数据卡的特工、编成卡背面、多行规则错位；必须逐件核对。
- 部分 manifest 标题/文件名含 `\x07` 控制字符（探路者无人机）。
- 部分卡图被裁、背面未切出 → 渲染 PDF 原页补。
- 卡图与勘误谁新谁旧要判断（取舍顺序见任务说明）。
- 本机无 `rtk`；临时 Python 脚本含中文需 `# -*- coding: utf-8 -*-` 或 `-X utf8`。
