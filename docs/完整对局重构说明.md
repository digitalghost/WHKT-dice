# 完整对局重构说明

更新：2026-09-23

## 目标

应用入口从单一攻防骰盘改为“对局记录中心”。一场对局直接选择双方已保存的小队，不再要求先把某一支小队设为“当前对局小队”。原有骰盘、武器档案预填和投掷解析继续复用。

规则依据为《杀戮小队 三版 官中修订版 v11.5》：核心流程见 PDF 第 7-10 页，认证行动任务包 2025 的设置、部署、转折点和结算见 PDF 第 105-107 页。可搜索原文位于 `杀戮小队三版官方规则-v11.5-全文提取.md`。

## 应用内流程

```text
对局记录中心
  ├─ 新建完整对局
  │    1. 选择双方玩家与小队
  │    2. 记录任务、杀戮区、关键行动与降落区
  │    3. 记录装备、战术行动与部署提示
  │    4. 核对并创建自动保存的对局
  ├─ 继续当前对局
  │    ├─ 每个转折点决定先手权
  │    ├─ 战略阶段
  │    ├─ 交战阶段
  │    ├─ 双方 CP / VP / 主要行动
  │    ├─ 双方特工耐伤、命令、就绪与残废状态
  │    └─ 从任一方特工的武器直接进入原骰盘
  ├─ 历史对局与结算摘要
  ├─ 小队管理
  └─ 自由骰盘
```

## 规则到实现的映射

| 规则 | 应用行为 |
|---|---|
| 设置战斗时双方选队 | 对局向导要求选择两支不同的已保存小队；同阵营可复制小队 |
| 确定杀戮区、地形图、关键行动、目标与降落区 | 向导记录任务、杀戮区、关键行动和双方降落区；实体目标摆放由玩家完成 |
| 秘密选择特工 | 以双方已保存编成为本场名单，并提示同时公开 |
| 最多选择 4 件装备选项 | 每方提供装备记录栏并显示上限提示；合法性由玩家判断 |
| 战前双方各获得 2CP | 新对局双方 CP 初值为 2 |
| 四个转折点 | 流程状态限制为四个转折点，第四个交战阶段后自动结算 |
| 每个转折点先手权、就绪、计划、交战 | 每轮先选择先手方，再依次进入战略和交战阶段；未残废特工在转折点开始时就绪 |
| 第一转折点双方各获得 1CP；之后无先手权方获得 2CP | 开始转折点时自动增加 CP |
| 第一转折点秘密选择主要行动 | 第一转折点不能离开战略阶段，直到双方主要行动已记录 |
| 关键、击杀、战术行动各最多 6VP | 三个计分器分别限制在 0-6 |
| 主要行动在战斗结束时奖励对应行动 VP 的一半，向上取整（PDF 107） | 对局中隐藏选择；结算时奖励 0–3VP，三类全满时总分为 21VP |
| 击杀等级按敌方起始人数查表 | 内置 PDF 第 107 页的 5-14 人击杀等级阈值，并显示当前等级 |
| 一方无特工时战斗仍继续 | 应用不会因全员残废自动结束；仍可完成剩余转折点 |

## 数据与兼容性

- `BattleRecord` 保存对局元数据、双方状态、当前阶段、先手权和时间线。
- `BattleSide` 保存玩家、小队快照、CP、三类 VP、主要行动、战前选择与特工状态；每名特工的本场武器档案也随对局快照保存，后续编辑小队不会改变进行中的对局。
- `BattleStore` 使用独立的 `SharedPreferences` JSON 存储，不修改原有小队存档格式。
- 旧的 `activeRosterId` 只保留给原成员/武器查看页兼容使用；完整对局不依赖它。
- 骰盘仍由 `MainActivity`、`RollLogic` 和 `DiceResultParser` 负责，未扩大自动规则裁定范围。

## 明确边界

应用负责记录和引导，不自动判断以下内容是否合法：编成、装备组合、目标选择、地形视线、计谋时机、行动限制和阵营专属规则。复杂武器规则仍按当前方式由玩家处理，避免改变已经稳定的投掷解析。
