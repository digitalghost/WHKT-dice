PDF 小队概述：银河中隐藏着许多可怕的黑暗秘密，而千子试图探索并发现这一切。通过召集各种巫师学徒、红字战士和疯狂变种人组成次元密会，他们使用巫术和蛮力将一切阻挡他们去路的事物驱逐。

### 2.2 当前阵容构成

一支次元密会杀戮小队由 **5 个特工选项**组成，从下列清单选择：

- 命运巫师（1 个选项）。
- 时间巫师（1 个选项）。
- 亚空间炽焰巫师（1 个选项）。
- 红字战士炮手（1 个选项）。
- 红字战士徽记持有者（1 个选项）。
- 红字战士战士（1 个选项）。
- 奸角兽勇士（半个选项）。
- 奸角兽号手（半个选项）。
- 奸角兽徽记持有者（半个选项）。
- 奸角兽战士（半个选项）。

必须至少选择一名己方**巫师**特工。除**战士**特工外，清单中的每种特工至多选择一次。KTDash 当前构成没有旧版“为一名巫师添加领袖关键词并增加耐伤”的步骤。

### 2.3 装备选择约束

- 每名巫师固定装备灵能杖、其数据卡上的灵能远程武器，并从下列三项中选择一项：地狱火爆矢手枪、普罗斯佩罗弯刀、亚空间炽焰手枪。
- 红字战士炮手选择“亚空间火焰喷射器 + 双拳”或“灵魂收割者炮 + 双拳”。
- 奸角兽勇士选择巨斧或巨剑。
- 奸角兽战士选择奸角兽双刃、奸角兽之刃和盾牌，或“自动手枪 + 链锯剑”。
- 整支小队至多包含一把亚空间炽焰手枪，且至多包含一门灵魂收割者炮。
- KTDash 的 `isDefault` 只表示网站默认勾选状态，不替代上述合法组合。

## 4. 阵营规则

### 4.1 奸奇恩惠（Boons Of Tzeentch）

关联 ID：`CHAOS-WC-SOD-A-BOT`、`CHAOS-WC-SOT-A-BOT`、`CHAOS-WC-SOW-A-BOT`。KTDash API 只为三种巫师分别提供总规则 ID；九种恩惠在 KTDash 小队网页中可见，但没有独立稳定 ID。

每当为战斗选择一名**巫师**特工时，必须为其选择一种奸奇恩惠，使其在整场战斗中拥有该恩惠。同一种奸奇恩惠每场战斗至多选择一次。

1. **虚化视觉（Incorporeal Sight）：**这名特工的远程武器获得“集中（Saturate）”。每当它执行射击时，敌方特工无法被遮蔽。
2. **时间行者（Time-Walk）：**这名特工的移动属性增加 `1"`。
3. **亚空间残响（Echoes From The Warp）：**每场战斗限一次，当这名特工进行反应时，可以改变其命令，并在该次反应中额外无消耗执行一个消耗 1AP 的行动；两个行动必须不同。
4. **亚空间强化（Warp Swell）：**这名特工近战武器的普通伤害属性增加 1。
5. **亚空间飞行（Immaterial Flight）：**每个转折点限一次，当这名特工在激活中执行冲锋或转移行动时可以飞行。不要正常移动；将其从杀戮区移除，再放置到完全位于其原位置一个等于移动属性的距离内的位置，只测量水平距离。在近距离战斗杀戮区中，距离不能穿过墙壁，也不能放置在访问点另一侧。该规则不会为冲锋增加额外距离。特工必须放在合法位置；除非执行冲锋，否则不能放入敌方特工控制范围。
6. **扭曲命运（Twist Of Fate）：**这名特工的灵能远程武器获得“关键穿刺 1（Piercing Crits 1）”。
7. **变异肢体（Mutant Appendage）：**敌方特工位于其控制范围内时，不会阻止它执行拾取标识或任务行动。每次激活限一次，它执行拾取标识、放置标识或任务行动时少消耗 1AP。
8. **星爆术（Astral Bombardment）：**选择这名特工的一件灵能远程武器，该武器获得“毁灭 1”。若选择裁决闪电，它仍获得“毁灭 1”，并以“爆炸 `2"`”替换原有“毁灭 2”。若选择烈焰风暴或焚却理智，每当亚空间炽焰巫师执行射击时，为该武器选择“追踪轻型”或“毁灭 1”，持续到行动结束；不能同时选择二者。
9. **非物质界专家（Master Of The Immaterium）：**这名特工所有具有距离要求的灵能行动，其距离要求增加 `3"`。对时间巫师的时空波动而言，只影响该规则第一个效果中的距离。

KTDash 网页英文当前效果：

- **Incorporeal Sight:** `This operative’s ranged weapons have the Saturate weapon rule. Whenever this operative is shooting, enemy operatives cannot be obscured.`
- **Time-Walk:** `Add 1" to this operative’s Move stat.`
- **Echoes From The Warp:** `Once per battle, when you counteract with this operative, you can change its order, and it can perform an additional 1AP action for free during that counteraction, but both actions must be different.`
- **Warp Swell:** `Add 1 to the Normal Dmg stat of this operative’s melee weapons.`
- **Immaterial Flight:** `Once per turning point, when this operative is performing the Charge or Reposition action during its activation, it can FLY. If it does, don't move it. Instead, remove it from the killzone and set it back up wholly within a distance equal to its Move stat of its original location, measuring the horizontal distance only. In a killzone that uses the close quarters rules, that distance cannot be measured over or through Wall terrain, and it cannot be set up on the other side of an access point. It gains no additional distance when performing the Charge action. It must be set up in a location it can be placed, and unless it is performing the Charge action, it cannot be set up within control range of an enemy operative.`

### 4.2 阿斯塔特（Astartes）

适用于六种拥有 `HERETIC ASTARTES` 关键词的巫师和红字战士特工。

在每一名己方次元密会阿斯塔特叛军特工的激活期间，它可以执行两次射击行动或两次近战行动。若两次射击都选择灵魂收割者炮或亚空间火焰喷射器，则第二次行动额外消耗 1AP。每次激活不能选择同一件灵能远程武器超过一次。无论拥有何种命令，每名己方次元密会阿斯塔特叛军特工都可以进行反应。

KTDash 英文原文：`During each friendly WARPCOVEN HERETIC ASTARTES operative’s activation, it can perform either two Shoot actions or two Fight actions. If it’s two Shoot actions and the soulreaper cannon or warpflamer is selected for both, 1 additional AP must be spent on the second action. You cannot select the same PSYCHIC ranged weapon more than once per activation. Each friendly WARPCOVEN HERETIC ASTARTES operative can counteract regardless of its order.`
