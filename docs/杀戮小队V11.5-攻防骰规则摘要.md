# 杀戮小队 V11.5 攻防骰规则摘要

整理日期：2026-09-22（Asia/Shanghai）

来源：《杀戮小队 三版 官中修订版 v11.5》PDF。该 PDF 整合了核心规则、通用装备、认证行动任务包 2025、官方 FAQ 和部分赛事 FAQ。

本文只整理会影响攻击骰、防御骰、重投、抵挡和伤害结算的规则。移动、任务、部署和完整地形判定不在本文展开。本文是供开发和快速回溯使用的摘要，不替代原规则书；出现歧义时以来源 PDF 的最新文本为准。

## 当前应用实现边界

- 应用自动判断攻击骰和防御骰的失败、普通成功与暴击。
- 应用按基础射击抵挡规则自动计算未被抵挡的普通攻击和暴击。
- 自动结算始终保留普通成功与暴击的类型：同类优先互相抵挡；普通成功已抵挡完后，剩余的每 2 个普通防御成功才抵挡 1 个暴击。绝不把 1 个暴击换算成 2 个普通成功。
- 重投是否合法、武器特殊规则、伤害和其他有争议的顺序由玩家自行处理。
- 下文仍保留完整相关规则，供玩家和后续开发回溯，不代表应用已经自动实现。

## 1. 最重要的术语

- **攻击属性 A**：使用武器时拿取的攻击骰数量。
- **命中属性**：攻击骰达到该数值即成功。
- **豁免属性**：防御骰达到该数值即成功。
- **普通成功**：成功但不是关键成功。
- **关键成功/暴击**：通常是结果 6，或由“致命”等规则产生。
- **失败**：未达到命中或豁免要求。结果 1 永远失败。
- **保留**：把一个结果确定为普通成功或关键成功。
- **舍弃**：从本次结算中移除该结果。
- **预留成功**：不掷某枚骰，直接保留为成功。预留骰没有点数，不能重投。
- **掩护**：目标从地形获得的规则状态，不等同于“掩体模型”。
- **掩护豁免**：因掩护而预留防御成功。
- **遮挡**：射击穿过重型地形等障碍时产生的攻击惩罚。
- **普通伤害/暴击伤害**：武器伤害栏的第一个/第二个数值。

除非规则明确说明，改变骰子的成功类型不会改变它原本的点数。

## 2. 通用掷骰规则

### 2.1 判断结果

按以下顺序判断一枚攻击骰或防御骰：

1. 结果 1 永远失败。
2. 成功且达到暴击门槛时为关键成功。
3. 其余达到命中或豁免门槛的结果为普通成功。
4. 其他结果失败。

“致命 X+”只能把已经成功的骰子变成关键成功。例如武器命中为 5+、致命 4+ 时，结果 4 仍然失败。

### 2.2 重投

- 同一枚骰子在同一次掷骰中最多重投一次。
- 必须接受重投后的结果，不能恢复旧结果。
- 攻击骰和防御骰必须在保留或舍弃前重投。
- 可以逐枚重投，并在看到前一枚的新结果后决定下一步。
- 如果双方同时拥有重投，从有先手权的玩家开始，双方轮流重投一枚或跳过；连续跳过后结束。
- 规则直接预留的成功没有点数，不能重投。
- 一枚骰被规则改成其他成功类型后，其原始点数不变。

### 2.3 同时生效的规则

- 一件武器可以同时拥有多条武器规则。
- 同一玩家控制的多个同时生效规则，由该玩家选择处理顺序。
- 相同规则通常不叠加；带 X 的相同规则按该规则的专门说明选择或合并。
- 应用不应替玩家隐藏有意义的顺序选择。

## 3. 射击完整流程

### 3.1 选择武器和目标

1. 攻击方选择远程武器，并按其攻击属性建立攻击骰池。
2. 选择有效目标。
3. 判断可见、命令、掩护、遮挡、制高点及其他目标限制。

目标是否合法和目标能否获得掩护豁免是两个不同问题。某些规则会让目标可被选择，但不会移除其掩护豁免。

### 3.2 掷攻击骰

1. 处理“精准”等预留成功。
2. 掷剩余攻击骰。
3. 进行合法重投。
4. 按命中、致命等规则分类。
5. 按玩家选择的顺序应用重击、撕裂、严重等转换规则。
6. 若目标被遮挡，处理遮挡效果。

### 3.3 遮挡

目标被遮挡时：

1. 攻击方选择并舍弃一个成功，普通或关键均可。
2. 剩余关键成功全部作为普通成功保留。
3. 这些普通成功不能再改回关键成功。

遮挡一般由阻碍射线的重型地形产生；轻型地形通常不能造成遮挡。若相关重型地形位于攻击者或目标 1 英寸内，通常不造成遮挡。

### 3.4 掷防御骰

1. 防御方通常拿取 3 枚防御骰。
2. “穿刺 X”会先减少拿取的防御骰数量。
3. 如果使用掩护豁免，从拿取的防御骰中拿出相应数量作为预留成功。
4. 掷剩余防御骰并进行合法重投。
5. 按豁免属性分类；结果 6 为关键成功，结果 1 永远失败。

普通掩护豁免：预留 1 个普通防御成功，不掷该枚骰。

强化版掩护豁免：防御方二选一：

- 预留 1 个关键防御成功；或
- 预留 2 个普通防御成功。

### 3.5 结算防御骰

防御方分配成功的防御骰抵挡成功的攻击骰：

| 防御骰 | 可以抵挡 |
|---|---|
| 1 个普通成功 | 1 个普通攻击成功 |
| 2 个普通成功 | 1 个关键攻击成功 |
| 1 个关键成功 | 1 个普通或关键攻击成功 |

抵挡分配可能有多种合法方案。规则没有要求防御方必须选择承伤最低的方案。

### 3.6 结算攻击骰和伤害

- 未被抵挡的普通成功造成普通伤害。
- 未被抵挡的关键成功造成暴击伤害。
- 一枚攻击骰只造成一次对应伤害；武器规则产生的额外伤害单独处理。
- 射击中的成功攻击骰视为同时结算。若某效果只对第一枚攻击骰减伤或无视伤害，由防御方从成功攻击中选择适用对象。
- 一些武器会在一次行动中对多个目标分别进行射击；通常在整个行动完成后再移除被残废的特工。

## 4. 掩护、遮挡和制高点

### 4.1 掩护

常见条件是阻碍地形位于目标控制范围内、对目标可见，且目标不在攻击者 2 英寸内。暴露地形不提供掩护。

拥有隐匿命令且有掩护的目标通常不是有效射击目标，但制高点、追踪等规则可能改变目标选择。

### 4.2 掩护与遮挡冲突

同一个地形部分同时满足掩护和遮挡时，防御方为该次射击选择其中一种效果，不能同时使用二者。

### 4.3 制高点

制高点常见的攻防效果：

- 攻击者高于目标至少 2 英寸但不足 4 英寸：远程武器获得“精准 1”。
- 攻击者高于目标至少 4 英寸：远程武器获得“精准 2”。
- 对低至少 2 英寸、拥有隐匿命令且由轻型地形提供掩护的目标，制高点可能使其仍可被选择。
- 上述目标仍保留强化版掩护豁免：预留 1 暴击或 2 普通成功。
- 判断遮挡时，通常忽略与攻击者所在制高点相连的重型地形。

### 4.4 烟雾

- 完全位于烟雾区域内的特工，对 2 英寸外的其他特工而言被遮挡；反向判断也相同。
- 对完全位于烟雾中的目标射击时，“穿刺 2”或“关键穿刺 2”降为对应的 1。

## 5. 射击相关武器规则

| 中文规则 | 常见英文 | 简化效果 |
|---|---|---|
| 精准 X | Accurate X | 不掷最多 X 枚攻击骰，直接把它们作为普通成功保留。多个精准效果按规则合并为精准 2，而不是任意累加。 |
| 平衡 | Balanced | 重投 1 枚攻击骰。 |
| 无休 | Ceaseless | 选择一个点数，可重投任意数量显示该点数的攻击骰。 |
| 毫不留情 | Relentless | 可重投任意攻击骰；每枚仍最多一次。 |
| 致命 X+ | Lethal X+ | 成功且结果达到 X+ 时为关键成功。 |
| 穿刺 X | Piercing X | 防御方少拿 X 枚防御骰。 |
| 关键穿刺 X | Piercing Crits X | 只有攻击方保留至少一个关键成功时，防御方才少拿 X 枚防御骰。 |
| 毁灭 X | Devastating X | 每个保留的关键成功立即对目标造成 X 点伤害；该关键成功仍继续参与抵挡和武器伤害结算。 |
| 重击 | Punishing | 若保留了关键成功，可把 1 个失败作为普通成功保留。 |
| 撕裂 | Rending | 若保留了关键成功，可把 1 个普通成功改为关键成功。精准预留的普通成功不能因此升级。 |
| 严重 | Severe | 若没有保留关键成功，可把 1 个普通成功改为关键成功。毁灭和关键穿刺仍可触发，重击和撕裂不能借此触发。 |
| 集中 | Saturate | 防御方不能使用掩护豁免，包括普通和强化版掩护豁免。 |
| 追踪 | Seek | 目标不能通过地形避免被选为有效目标；不自动移除其掩护豁免。 |
| 追踪轻型 | Seek Light | 只忽略轻型地形对目标选择的保护；不自动移除掩护豁免。 |
| 范围 X | Range X | 只有位于 X 英寸内的目标有效。 |
| 安静 | Silent | 使用者拥有隐匿命令时也可用该武器射击。 |
| 重型 | Heavy | 使用过该武器的激活或反应期间限制移动；括号内可列出允许的移动。 |
| 有限 X | Limited X | 每场战斗最多使用 X 次。一次行动内的多次使用通常计为一次。 |
| 过热 | Hot | 使用后掷 1D6；若低于当次有效命中属性，使用者受到点数两倍的伤害。 |
| 晕眩 | Stun | 保留关键成功后，目标 APL -1，直到其下一次激活结束。 |

“毁灭 X”造成的是额外伤害，不属于攻击骰本身的伤害。只减少或无视“攻击骰伤害”的规则通常不能处理这部分额外伤害。

### 5.1 爆炸 X

- 先正常选择并射击主要目标。
- 随后对主要目标 X 英寸内、且对主要目标可见的每个次要目标分别射击。
- 次要目标不需要再次被“选择”，因此只禁止被选择的规则通常无效。
- 主要目标的掩护和遮挡判定通常直接应用给次要目标。
- 每个目标单独建立和结算一套骰池。

### 5.2 洪流 X

- 先选择一个有效的首要目标。
- 可选择首要目标 X 英寸内的其他有效目标作为次要目标，但不能选择处于己方特工控制范围内的目标。
- 各目标分别掷骰和结算，顺序由攻击方决定。
- 每个目标独立判断掩护和遮挡。

## 6. 近战

近战不是“攻击骰对防御骰”。双方都掷攻击骰。

### 6.1 建立骰池

1. 主动方选择控制范围内的一名敌方特工。
2. 双方各选一件近战武器。
3. 双方同时掷各自的攻击骰并分类。
4. 合法协助可使近战武器命中改善 1 点；多名协助者可以叠加，但结果 1 仍永远失败。

### 6.2 轮流结算

- 主动方先开始。
- 双方轮流结算 1 个尚未结算的成功，直到一方没有成功，或一名特工被残废。
- 每次选择“出击”或“格挡”。

出击：

- 普通成功造成普通伤害。
- 关键成功造成暴击伤害。

格挡：

- 1 个普通成功抵挡对手 1 个普通成功。
- 1 个关键成功抵挡对手 1 个普通或关键成功。
- 格挡不能撤销已经结算的出击。
- 即使对手已没有成功，仍可选择格挡而不是出击。

### 6.3 近战相关武器规则

| 规则 | 效果 |
|---|---|
| 残暴（Brutal） | 对手只能用关键成功格挡。 |
| 震荡（Shock） | 每次结算中第一次用关键成功出击时，舍弃对手 1 个未结算普通成功；若没有普通成功，舍弃 1 个关键成功。 |
| 晕眩（Stun） | 保留关键成功后使目标 APL -1，直到其下一次激活结束。 |

双方在近战中同时拥有重投时，按“有先手权者开始、轮流一枚”的通用重投规则处理。

## 7. 通用计谋和装备的攻防影响

### 7.1 指挥重掷

在掷攻击骰或防御骰后使用，重投其中 1 枚。该骰仍受“同一枚骰最多重投一次”限制。

### 7.2 弹药储备

符合条件的特工射击时可重投 1 枚攻击骰。它与其他重投共享同一枚骰不能重复重投的限制。

### 7.3 可移动掩体的保护

特工从该掩体获得掩护时，豁免改善 1 点，最多改善到 2+。

### 7.4 受创

特工剩余耐伤低于起始耐伤一半时受创。其移动减少 2 英寸，武器命中恶化 1 点。受创不会直接改变豁免。

## 8. 容易实现错误的例外

1. **预留成功没有点数。** 不能重投，也不能假设它是 6。
2. **类型变化不改点数。** 把失败当成功或把普通成功当暴击，不会改变原始点数。
3. **致命先要求成功。** 低于命中值的结果不能只因达到致命门槛而变成暴击。
4. **精准与撕裂有专门限制。** 精准预留骰不能被撕裂升级为暴击。
5. **严重有专门触发关系。** 它生成的暴击可触发毁灭和关键穿刺，不能反过来触发重击和撕裂。
6. **追踪不等于取消掩护豁免。** 它主要改变目标选择。
7. **集中才会禁止掩护豁免。** 包括制高点产生的强化版掩护豁免。
8. **遮挡处理后不能重新升暴击。** 遮挡降级的结果具有更高优先级。
9. **穿刺先改变防御骰池。** 再从剩余骰池中预留掩护成功。
10. **重投限制跟随具体骰子。** 更换点数、改变成功类型或恢复历史状态都不能清除“已重投”状态。
11. **近战没有防御骰。** 不能复用射击的攻击-防御抵挡模型。
12. **忽视武器属性修正不等于忽视减伤。** V11.5 FAQ 区分了“修改伤害属性”和“减少实际受到的伤害”。

## 9. 面向应用的数据要求

为了正确支持上述规则，不能只保存成功数量。每枚骰至少需要以下信息：

```text
唯一索引
当前点数
原始点数
当前分类：失败 / 普通成功 / 关键成功
来源：实际投出 / 规则预留
是否已重投
应用过的转换规则
是否已舍弃
是否已用于抵挡
```

一次射击建议按以下阶段建模：

```text
建立攻击骰池
-> 预留攻击成功
-> 掷攻击骰
-> 重投
-> 分类与玩家选择的转换
-> 遮挡
-> 确定穿刺和防御骰池
-> 预留掩护成功
-> 掷防御骰与重投
-> 分配抵挡
-> 结算额外伤害与武器伤害
```

程序可以检查合法性、列出可选操作、枚举抵挡方案并推荐低伤害方案，但不应自动吞掉以下玩家选择：

- 多个同时生效规则的顺序。
- 遮挡时舍弃哪个成功。
- 强化版掩护选择 1 暴击还是 2 普通成功。
- 防御成功如何分配。
- 近战中选择出击还是格挡。
