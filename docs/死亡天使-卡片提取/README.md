## 输出规格

- 特工卡：`954 x 553 px`，横向，200 DPI 页面渲染后裁切。
- 规则卡：`556 x 960 px`，纵向，200 DPI 页面渲染后裁切。
- 裁切保留卡片边框和裁切定位线，不包含相邻卡片内容。
- `manifest.json` 保存每张卡片的类别、源页、页内顺序、裁切坐标和关联角色 ID。
