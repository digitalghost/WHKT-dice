### 4.1 钻地（Burrow）

- KTDash 关联 ID：`TYR-RAV-PRM-BUR`（其他角色各有同义的角色级 ID）
- 卡图：[说明](./蛇虫-卡片提取/10-阵营规则-钻地-说明.png) / [行动](./蛇虫-卡片提取/11-阵营规则-钻地-行动.png)

当前采用的中文全文：

> 蛇虫会从地下隧道上破土而出，对目标发动奇袭，在敌人能够做出反应前又消失不见。
>
> 在战斗开始前部署蛇虫杀戮小队时，您的前两个特工必须照常进行部署。在那之后的每一名其他己方蛇虫特工可以被部署在地下；将它们放在一边而不是在杀戮区中。
>
> 在交战阶段中，被部署在地下的己方蛇虫特工可以照常进行激活和反应。当己方蛇虫特工位于地下时，那名特工不能执行钻地以外的行动。在战斗结束时，每一个位于地下的己方蛇虫都将被残废。
>
> 己方蛇虫特工可以执行以下独特行动：
>
> **钻地（1AP）**
>
> - 如果该特工位于地下，将该特工部署在您的隧道上可以被部署的位置（特工不再位于地下，并且可以被部署在敌方特工的控制范围内）。直到那次激活或反应结束前，该特工的移动属性减少 2"。
> - 除此之外，作为上述效果的替代效果，如果该特工位于杀戮区中并且位于您的隧道上，那么将其移出杀戮区：特工现在位于地下。
> - 一名特工不能在携带一个标识期间执行本行动，也不能在不位于地下或者己方隧道的情况下执行本行动。

KTDash 英文全文（接口原文）：

> When setting up a RAVENER kill team before the battle, your first two operatives must be set up as normal. Each other friendly RAVENER operative thereafter can be set up underground: place it to one side instead of in the killzone.
>
> In the Firefight phase, friendly RAVENER operatives set up underground are activated and can counteract as normal. Whenever a friendly RAVENER operative is underground, it cannot perform any actions other than Burrow. At the end of the battle, each friendly RAVENER operative that’s underground is incapacitated.
>
> Friendly RAVENER operatives can perform the following action:
>
> **BURROW (1 AP):** If this operative is underground, set it up on your TUNNEL in a location it can be placed (it’s no longer underground, and it can be set up within control range of enemy operatives). Until the end of the activation/counteraction, subtract 2" from its Move stat. Alternatively, instead of resolving the above effect, if this operative is in the killzone and on your TUNNEL, remove it from the killzone: it’s now underground. An operative cannot perform this action while carrying a marker, or if it isn’t either underground or on your TUNNEL.

### 4.2 隧道（Tunnel）

- KTDash 关联 ID：`TYR-RAV-PRM-A-TUN`
- 卡图：[1/2](./蛇虫-卡片提取/12-阵营规则-隧道-1.png) / [2/2](./蛇虫-卡片提取/13-阵营规则-隧道-2.png)

当前采用的中文全文：

> 蛇虫会在猎物脚下的土地和地基中挖掘错综复杂的隧道，让这群虫群意志的精英生物体能够伏击目标。
>
> 在部署特工步骤结束时，将一个编号为“0”的隧道标识放在杀戮区的地面上，完全位于己方杀戮区内且与己方杀戮区边缘触碰的位置。在前四个转折点中，作为一个战略计划，您可以将您下一个标号的隧道标识放置在杀戮区地面上完全位于上一个隧道标识 5" 内的位置。这意味着，随着战斗的进行，您可能会拥有一系列按照数字顺序放置的隧道标识（0，1，2，3 和 4）。在您放置了五个隧道标识后，不要放置更多的隧道标识（如果战斗的时长超过四个转折点的话）。
>
> 按照数字顺序，隧道标识之间的区域（例如 0 与 1 之间，1 与 2 之间，等等）构成您的隧道。
>
> 在使用近距离战斗规则的杀戮区中（例如杀戮区：墓穴世界），您的隧道以及隧道标识之间的距离可以穿过墙壁地形进行测量。在一个使用危险区域规则的杀戮区中（例如杀戮区：贝赫塔-狄希玛），在判断受限移动规则时，与危险区域触碰的隧道标识被视作为危险区域。
>
> 在卡图的例子中，由于特工 A 位于标识 0 和 1 之间的区域上，因此该特工位于您的隧道上。特工 B 与您的一枚隧道标识触碰，因此该特工也位于您的隧道上。由于标识 1 与 3 没有按照次序，因此它们之间的区域不是您的隧道，特工 C 也不位于您的隧道上。

KTDash 英文全文（接口原文；接口句法有缺词，未擅自修订）：

> At end Set Up Operatives step, place Tunnel marker numbered `0` on killzone floor, wholly within drop zone touching killzone edge. As STRATEGIC GAMBIT in first four turning points, you can place next numbered Tunnel marker on killzone floor wholly within 5" preceding Tunnel marker. This means that, as battle progresses, you can series sequentially numbered Tunnel markers (0, 1, 2, 3 4). Once you placed five Tunnel markers, don’t place any more (i.e. if battle lasts more four turning points). Your Tunnel markers area sequentially numbered markers (i.e. between 0 1, 1 2, etc.), create TUNNEL. In killzone uses hazardous areas rules (e.g. Killzone: Bheta Decima), for purposes Restricted Movement rule, parts Tunnel marker that touching hazardous area treated as hazardous area. In killzone uses close quarters rules (e.g. Killzone: Tomb World), your TUNNEL and distance between Tunnel markers can be measured through Wall terrain.

> **问：** 如果一名颤镰蛇虫特工尝试使用地底伏击规则指定的目标进行射击或近战，但是被对手的规则阻止（如净化者忏悔士的激昂宣令、见习修女的致盲光环），那么那名己方特工的激活是否被取消？
