## 4. 阵营规则

### 1. 钻地（BURROW）

**卡图**：[11-01-阵营规则-钻地-1.png](蛇虫-卡片提取/11-01-阵营规则-钻地-1.png) [11-02-阵营规则-钻地-2.png](蛇虫-卡片提取/11-02-阵营规则-钻地-2.png)

**源页**：PDF 第 3 页

**中文全文**

蛇虫会从地下隧道上破土而出，对目标发动
奇袭，在敌人能够做出反应前又消失不见。
在战斗开始前部署蛇虫杀戮小队时，您的前两
个特工必须照常进行部署。在那之后的每一名其
他己方蛇虫特工可以被部署在地下；将它们放
在一边而不是在杀戮区中。
在交战阶段中，被部署在地下的己方蛇虫特工
可以照常进行激活和反应。当己方蛇虫特工位
于地下时，那名特工不能执行钻地以外的行动。
在战斗结束时，每一个位于地下的己方蛇虫都
将被残废。
己方蛇虫特工可以执行以下独特行动：
钻地 1AP
如果该特工位于地下，将该特工部署在您的
隧道上可以被部署的位置（特工不再位于地
下，并且可以被部署在敌方特工的控制范围
内)。直到那次激活或反应结束前，该特工
的移动属性减少 2"。
除此之外，作为上述效果的替代效果，如果
该特工位于杀戮区中并且位于您的隧道上，
那么将其移出杀戮区：特工现在位于地下。
一名特工不能在携带一个标识期间执行本行
动，也不能在不位于地下或者己方隧道的情
况下执行本行动。

**English full text**

RAVENER
FACTION RULE
BURROW
Raveners will emerge from their tunnels to strike at
unsuspecting victims, then disappear again before their
foe can properly react.
When setting up a RAVENER kill team before the
battle, your first two operatives must be set up as
normal. Each other friendly RAVENER operative
thereafter can be set up underground: place it to
one side instead of in the killzone.
In the Firefight phase, friendly RAVENER
operatives set up underground are activated and
can counteract as normal. Whenever a friendly
RAVENER operative is underground, it cannot
perform any actions other than Burrow. At the
end of the battle, each friendly RAVENER
operative that’s underground is incapacitated.
Friendly RAVENER operatives can perform the
following unique action:
BURROW 1AP
If this operative is underground, set it up
on your TUNNEL in a location it can be
placed (it’s no longer underground, and
it can be set up within control range of
enemy operatives). Until the end of the
activation/counteraction, subtract 2" from
its Move stat.
Alternatively, instead of resolving the above
effect, if this operative is in the killzone
and on your TUNNEL, remove it from the
killzone: it’s now underground.
An operative cannot perform this action
while carrying a marker, or if it isn’t either
underground or on your TUNNEL.

### 2. 隧道（TUNNEL）

**卡图**：[11-03-阵营规则-隧道-1.png](蛇虫-卡片提取/11-03-阵营规则-隧道-1.png) [11-04-阵营规则-隧道-2.png](蛇虫-卡片提取/11-04-阵营规则-隧道-2.png)

**源页**：PDF 第 3、4 页

**中文全文**

蛇虫会在猎物脚下的土地和地基中挖掘错综
复杂的隧道，让这群虫群意志的精英生物体
能够伏击目标。
在部署特工步骤结束时，将一个编号为“0”的
隧道标识放在杀戮区的地面上，完全位于己方杀
戮区内且与己方杀戮区边缘触碰的位置。在前四
个转折点中，作为一个战略计划，您可以将您下
一个标号的隧道标识放置在杀戮区地面上完全位
于上一个隧道标识 5" 内的位置。这意味着，随着
战斗的进行，您可能会拥有一系列按照数字顺序
放置的隧道标识（0，1，2，3 和 4)。在您放置了
五个隧道标识后，不要放置更多的隧道标识（如
果战斗的时长超过四个转折点的话)。
按照数字顺序，隧道标识之间的区域（例如 0 与
1 之间，1 与 2 之间，等等）构成您的隧道。
在使用近距离战斗规则的杀戮区中（例如杀戮
区：墓穴世界)，您的隧道以及隧道标识之间的距
离可以穿过墙壁地形进行测量。在一个使用危险
区域规则的杀戮区中（例如杀戮区：贝赫塔-狄希

**先前的规则注解**

本章节对与罕见或复杂规则互动时遇到的问题进行解答。
问: 在结算植入战术行动的第二胜利点规则时，位于地下的 蛇虫  特
工是否算作“位于杀戮区中”？
答: 算作。请注意，其他战术行动（例如监视）依旧会需要这些特工
位于杀戮区内。
问:  如果杀戮区中还存在其他就绪的 蛇虫  特工，那么一名处于待机
状态的己方颤镰特工是否可以在进行反应时使用地底伏击规则来打断
敌方特工的激活？
答:  可以。
问:  在己方颤镰特工打断对手的激活时，如果被打断的敌方特工被残
废（并且因此无法被激活），那么哪一方玩家激活下一名特工?如果
在同样的情况中，敌方特工没有被残废并且继续执行激活，那么哪一
方玩家激活下一名特工？
答:   您的对手都将在上述两种情况中激活下一名特工，因为颤镰特工
使用了您的激活。

问:  如果一名颤镰蛇虫特工尝试使用地底伏击规则指定的目标进行射
击或近战，但是被对手的规则阻止（如 净化者  忏悔士的激昂宣令，
见习修女  的致盲光环），那么那名己方特工的激活是否被取消？
答:  不会。照常进行那次激活/反应，将地底伏击规则的条件视作为
被完成。
