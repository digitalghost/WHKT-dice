# 杀戮小队编成模块

更新：2026-09-23

## 目标与边界

本模块让玩家从角色卡库中选择成员、配置武器并保存自己的杀戮小队。应用只记录玩家的选择，不解析或判断队伍编成、人数、角色与武器搭配是否合法。

## 当前功能

- 内置死亡天使、瘟疫战士、蛇虫 3 支小队，共 22 种成员卡。
- 可新增、编辑、复制和删除成员。
- 每名成员可以填写自定义称号并自行勾选武器。
- 每支小队的名单分别保存到本机，重新进入应用后恢复。
- 切换卡库或返回时，如有未保存修改，会提示保存或放弃。
- 手机使用“成员卡库 / 我的小队”标签切换；平板使用左右双栏。

## 卡片与照片

- 默认不显示角色头像，也不从规则卡片中裁切头像。
- 候选成员、已选成员和成员编辑窗口都提供“查看卡片”按钮。
- 点击按钮后，以半透明遮罩浮层完整展示角色卡片；图片按比例完整显示，不裁切。
- `RosterMember.customAvatarUri` 预留玩家拍摄棋子照片的位置；未拍照时为 `null`，界面不显示头像。
- 拍照功能尚未开放；开放后仅在玩家确实拍摄过照片时显示头像。

## 数据结构

```text
RosterCatalog
  └─ KillTeamCatalog
       └─ OperativeTemplate
            └─ WeaponOption

SavedRoster
  └─ RosterMember
```

- `RosterCatalog`：内置的小队、角色和武器卡库。
- `SavedRoster`：一支卡库对应的一份玩家名单。
- `RosterMember`：已选成员、自定义称号、武器选择和可选照片地址。

## 保存规则

- 名单按小队 ID 分开保存，切换卡库不会互相覆盖。
- 修改名单名称或成员后进入“未保存”状态。
- 点击保存后写入 `SharedPreferences` 中的 JSON 数据。
- 应用不自动纠正或删除玩家认为合法的重复成员与武器组合。
