## 一、测试目标与核心原则

1. **严格按官方编成规则组队参战**：
   - 每支小队均严格对照其官方「小队选择 / 编成与武器选择」规则（人数上限、领袖必选、专家/枪手/重武器手限额、半格随从配对、默认合法武器配装）生成标准合法编成（固化于 [`CanonicalRosters.kt`](../app/src/main/java/com/example/helloworld/CanonicalRosters.kt) 并通过 [`AllTeamsBattleSimulationTest.kt`](../app/src/test/java/com/example/helloworld/AllTeamsBattleSimulationTest.kt) 与 [`RosterCompositionTest.kt`](../app/src/test/java/com/example/helloworld/RosterCompositionTest.kt) 自动化校验）。
     > **【复核 2026-11-01 · 有问题 → 已修正】** 原文引用了不存在的 `RosterValidationTest.kt`，已修正为实际的 `AllTeamsBattleSimulationTest.kt` 与 `RosterCompositionTest.kt`。
2. **优先验证系统通用例外/规则干预机制，不盲目硬编码**：
   - 本应用作为「规则引导型桌面辅助记录系统」，核心目标是**在核心规则引导下，通过完备的通用例外/干预工具，顺畅记录并运转所有小队的特殊独立规则**。
   - 若系统现有的通用例外操作（如 `按规则例外记录`、`＋ 修饰`、`＋ 不掷骰预留`、`改判/改点数`、`更换数据卡`、`借用/手填武器`、`＋ 特工`、`临时控制`、`规则：顺序`、`额外激活`、`联合激活`、`计数器`、`状态标记`、`独特行动`）能够自然满足某支小队的特殊规则，则视为系统验证通过，无需为每条特殊规则编写专门硬编码。
   - 仅当遇到**程序崩溃、UI/UX 阻塞（如软键盘遮挡、弹窗误关、按钮滚出视野）、核心流程卡死、或 JSON 数据/武器缺失错误**时，才针对性修复代码或数据。
3. **对局完整度与频次要求**：
   - 全 48 支小队两两捉对（共 **24 场完整对战**），每支小队至少完成 1 场完整对战。
   - 每场对战必须从战前配置（选编成、选关键行动/战术行动、勾选双方 4 件装备）开始，完整走完 **TP1 → TP2 → TP3 → TP4 的全部三个阶段（先手·就绪 → 战略 → 交战）**，直至进入终局 **`对局总结`** 页面并核对总分与完整日志。

## 二、测试方法与标准化执行过程

### 1. 小队独立规则 → 系统通用干预工具映射矩阵

在每场捉对对战前，先梳理参战双方小队的全部独立规则，并在实机对局中逐项映射到系统现有的 13 类通用工具进行实操验证：

### 2. 单场对战标准测试步骤
1. **战前准备**：在主页注入/选择参战双方标准合法编成（`CanonicalRosters`），填写关键行动、双方战术行动、勾选双方阵营装备与通用装备，开启新对局。
2. **TP1 完整推演**：
   - `先手·就绪`：执行双骰拼点（验证平局规则与先手权卡），选择先手方，验证 CP 自动发放与小队计数器重置。
   - `战略阶段`：双方秘密选择主要行动（验证界面隐藏显示 `已选（隐藏）`），轮流使用 `1CP 战略计谋` 与 `0CP 战略计划 / 阵营规则`（验证子项芯片一键填入与重复使用拦截）。
   - `交战阶段`：轮流激活双方特工，完整覆盖**远程射击**（含掩护、遮挡、烟雾、穿刺、毁灭、致命、撕裂、重击、严重、过热、爆炸/洪流多目标连射）、**近战搏斗**（含先攻、双方重投、出击/格挡交替结算、残暴、震荡、护盾/镇压双格挡、粉碎对抗骰）、**独特行动**与上述 **13 类通用规则干预操作**。
3. **TP2 → TP3 → TP4 持续推进**：
   - 验证跨转折点状态清理（`本转折点结束` 标记自动移除、`下一次激活结束` 标记在对应特工激活结束时移除、每转折点计数器自动重置）。
   - 验证特工残废、免于残废（`医疗兵！` / `沧桑老兵`）、复活返场（`重生规程`）、`狂暴` 延迟残废、`不计入击杀` 随从及动态击杀等级 VP 计算。
   - 验证在双方仍有就绪特工时点击 `结束转折点` / `提前结束战斗` 的二次确认弹窗，以及全部特工待机后直接进入下一转折点。
4. **TP4 终局结算（`对局总结`）**：
   - 验证第 4 转折点结束后自动揭晓双方秘密选择的 `主要行动`、自动按 `ceil(单项得分 / 2)` 计算主要行动奖励 VP、汇总关键/击杀/战术/主要奖励四项得分、核对在场/离场人数统计与 `完整记录` 日志条数。
