## 1. 整理原则与范围

### 1.1 本次数据口径

本轮整理**唯一采信官方中文 PDF**，不引用 KTDash 的任何数值或 ID。核对期间
`ktdash.app` 无法稳定访问（DNS 解析正常，但 TLS 握手在 ClientHello 后被立即断开，
`curl` / `openssl` / 无头 Chrome / 境外出口代理均失败），无法保证「网站当前值」可复现。

英文对照取自官方同批英文版 PDF。两版页面尺寸与卡片切分位置逐张一致，
因此中英配对是版面级确定性的（35/35 张精确对齐），不含任何推测性翻译。

问:  若我使用了独赏自恶计谋并且我的对手在我激活一名特
工前激活了他最后两名特工（例如族群裔兵   成队激活，远
行者猎手   羁绊稳固），我是否可以在这些激活之间进行激
活？
答:  不可以。 在这些情形下您不会获得常规的激活机会，所
以屠戮之翼  特工会是转折点中最后激活的特工。

问:  在诅咒利爪特工的抓取行动中，要求敌方特工“并且不
能进一步将其放置在离初始位置更远的地方。”应该怎么理
解？
答:  当敌方特工在那次行动中被移除后，若它距离诅咒利爪
特工 X"，则它必须被部署在 X" 内。换言之，若它被部署在推
进区域，它就必须被部署在同一个位置或者距离诅咒利爪结
束推进时更近的位置。
