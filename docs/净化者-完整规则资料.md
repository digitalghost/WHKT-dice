Book), don’t remove it from the killzone until this rule has been resolved.

智天使：

Cherub:
• Whenever determining control of an objective marker, treat
this operative’s APL stat as 1 lower. Note this isn’t a change
to its APL stat, so any changes are cumulative with this.
• Whenever this operative has a Conceal order and is in cover,

over all other rules (e.g. Seek, Vantage terrain) except being
within 2".

**先前的规则注解**

本章节对与罕见或复杂规则互动时遇到的问题进行解答。
问: 一些规则会要求特工对特定的目标进行射击或近战，或者
取消特工的一次激活。如果对手使用了这样规则，并且己方
净化者忏悔士特工通过激昂宣令规则取消了那次射击或近
战，那么该如何结算？
答: 不要取消敌方特工的激活。除了被正常阻止的行动之外，
那名特工可以照常继续执行行动。
问: 如果忏悔士特工的“激昂宣令”规则阻止一名处于戒备
的特工进行射击或近战行动，那么那名敌方特工是否保持戒
备状态？
答: 是的，前提那名特工已经满足保持戒备状态的所有其他
条件。

问: 如果对手使用了需要特工执行射击或近战行动的交战计谋
（例如：远行者猎手   的严密防御），并且己方 净化者忏
悔士特工通过激昂宣令取消了那次行动，那么是否返还 CP？
答: 不会。除此之外，任何拥有使用次数限制的规则（例如：
虚空创痕海盗   费拉奇的领先一步）在被阻止后依旧也会算
作被使用。
问: 如果净化者忏悔士特工使用激昂宣令规则取消了一次对
手通过戒备使特工进行的射击或近战，那么对手是否可以在
那次打断中选择执行其他行动？
答:  可以。
