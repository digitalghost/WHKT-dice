# 轻量对局记录台（2026-09-23）

本说明取代此前“完整对局规则核查与验收”中的强制流程设计。根据用户反馈，应用只负责记录，不担任规则裁判。

## 用户流程

1. 为双方选择已保存的小队，可查看角色与完整武器配置。允许双方使用同一份编成。
2. 分别选择装备卡，可查看完整阵营原卡和通用装备说明。开始前可以留空，进入对局后继续选。
3. 可选关键任务，然后直接进入记录台。不需要部署确认、拼骰先手、战略计划、激活或 AP 门槛。
4. 点击角色的武器，查看武器数据并投掷。不强制指定受击方；投掷算法保持原样。
5. 玩家在线下结算，再记录任意一方角色剩余耐伤、残废状态、VP、CP 或文字备注。不会自动扣血、残废或增加 CP。

## 界面

首页、新建对局、记录台及新卡片页统一使用自绘背景、自定义按钮和对话框内容，不采用系统默认选择列表或复选框。手机用双方切换标签，平板左右并列。详细操作收进装备/战术、计分和更多页；不再铺满阶段规则。

## 卡片来源与边界

- 任务：用户提供风来西 vol.1.29 速查图，9 张关键目标（2025）与 12 张战术目标（2026），每张都有规则、公开时机（适用时）和得分说明。完整速查原图可缩放。版本歧义明确提示；不自动判断目标控制、任务完成或得分。
- 通用装备：用户提供 PDF 第 1 页，共 10 项。逐项整理为卡片，并保留完整原页缩放入口。文字摘录见《通用装备卡摘录.md》。
- 阵营装备：使用项目已有死亡天使、瘟疫战士、蛇虫各 4 张原卡，按当前小队阵营展示，共 12 张。不跨阵营列出，也不编造缺失资料。
- 选择装备保存在双方各自的对局快照中。修改编成不会回写正在进行的对局。旧对局及旧装备备注保留。
- 装备、手雷组合和特殊阵营能力的使用时机由玩家判定；装备选择不会静默修改骰子规则。组合具体分配可记录到对局备注。
- 主要行动可选填，未选则不加奖励；选择后终局加对应 VP 的一半、向上取整。击杀奖励由玩家计入手动分数。

## 验证

- 36 项单元测试通过，包含镜像编成双方耐伤、残废、CP、VP、装备独立性，以及 21 张任务、10 项通用装备内容完整性。
- debug APK 构建和 Android Lint 通过（保留既有非阻断警告）。
- 手机和平板模拟器均安装并打开；手机实测装备原卡查看与选取、手动耐伤保存、直接选择武器进入投掷；旧对局加载正常。
- 对局自动保存，支持撤销与记录导出。投掷历史恢复时取消当前对局关联，避免历史重投误写入对局。
