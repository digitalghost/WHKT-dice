问:  “坚定守卫”规则如何与将敌方特工的 APL 属性视为比

答:  “坚定守卫”规则会将受影响的特工的 APL 属性视为 3
，但是在争夺一个标识时，APL 总数会降低 1 点。例如，如果
一名争夺标识的己方特工拥有“坚定守卫”规则，并且在同时
受到了“恐惧”规则的影响，那么它的 APL 总数会是 2；如果
有两名处于上述状态的己方特工争夺一个标识，那么 APL 总
数为 5。
问:  一名进行戒备的特工是否可以进行打断并使用增幅武器
规则对位于另一个己方特工控制范围内的敌方特工进行零距
离射击？
答: 不能。
