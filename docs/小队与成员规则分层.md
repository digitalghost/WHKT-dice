# 小队与成员规则分层

## 小队资料

战略计谋、战术计谋（原卡称“交战计谋”）作为一级入口，统一属于小队。阵营与通用规则另设入口，编成、装备、标识和勘误作为补充资料。小队目录不再混入所有角色的能力章节。

## 成员规则

只展示该角色的专属能力、特殊行动及原卡。角色自身影响全队计谋的能力（例如“英雄领袖”“条令战争”）仍属于角色，应保留；不能因为描述出现“计谋”就删除。

成员详情只提供“小队计谋”“阵营与通用规则”导航，不重复展开共享内容。成员列表改为一个紧凑的能力入口，不再逐条堆叠共享规则。

次元密会按具体角色筛选能力，不把红字战士或奸角兽共用资料章节中的其他角色能力带入当前成员。蛇虫采用含勘误的角色正文。

死亡天使、瘟疫战士的小队计谋使用项目已提取的原卡；次元密会、蛇虫保留规则文字与对应原卡。此调整不修改编成、对局记录、投掷逻辑或计谋结算方式。
