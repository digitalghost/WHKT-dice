## 数据和展示

- 角色保留中文名称、定位、APL、移动、豁免、耐伤、底座和关键词。
- 每个武器档案使用独立稳定 ID；同名远程／近战武器区分显示，按来源的 R/M 类型决定“射击／交战”。多档案不合并或漏掉。
- 来源标为默认的武器保留其所有档案；需用户选配的武器不擅自默认勾选。编成页保留选择权，编成约束在小队资料中完整显示。
- 小队共享规则按标题与完整正文去重，位于小队资料顶部；成员专属能力按角色归属展示，AP 保留原值，包括 0 AP。
- 每队各 4 项战略计谋、4 项交战计谋、4 项阵营装备；计谋费用来自资料记录。装备选择直接显示当前中文效果，原卡另可放大查阅。
- 保留小队编成、标识指南，以及来源中存在的 PDF 专属问答。洁天使隐伏者的反灵能者定义采用资料中的 PDF-only 解释。
- 速查增加维度放逐、护盾、洪流 0 英寸、反灵能者；护盾不混用次元密会盾牌的豁免规则。
- 原卡未经改字或重绘。显示当前数值和文本时以核对资料为准，纸面原卡可能是旧版。

## 生成与验证

运行 `python3 tools/import_prepared_teams.py` 可重新生成 `ImportedTeamCatalog.kt`、三队规则 JSON 及对应卡图资源。生成过程逐字段核对角色属性、武器类型、55 条档案的 ATK/HIT/DMG/WR 与 API 快照，并检查来源关联。其余手写 UI 集成不由脚本覆盖。

验证已完成：49 项单元测试、`:app:lintDebug`、`:app:assembleDebug`；手机选队与角色列表检查；平板对局中三队的射击／交战入口、成员专属能力、小队规则、计谋、当前装备正文检查。UI 检查使用临时模拟器对局，结束后恢复原始对局数据。
