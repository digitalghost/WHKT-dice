## 1. 整理原则与范围

### 1.1 本次数据口径

本轮整理**唯一采信官方中文 PDF**，不引用 KTDash 的任何数值或 ID。核对期间
`ktdash.app` 无法稳定访问（DNS 解析正常，但 TLS 握手在 ClientHello 后被立即断开，
`curl` / `openssl` / 无头 Chrome / 境外出口代理均失败），无法保证「网站当前值」可复现。

因此中英配对是版面级确定性的（36/36 张精确对齐），不含任何推测性翻译。
