# 蛇虫杀戮小队卡片提取

来源：[`../蛇虫 Raveners 杀戮小队规则.pdf`](../蛇虫%20Raveners%20杀戮小队规则.pdf)

本目录从原 PDF 第 1-7 页提取了 28 张实体卡片，另附 2 张总览图。第 8-9 页为更新日志、规则注解和先前勘误，第 10-14 页为特工介绍、模型选项和设计师注解，不作为卡片裁切。

卡片按 PDF 页码及页内从上到下、从左到右的阅读顺序编号。第 3-4 页的“钻地”和“隧道”规则跨多张卡片，仍逐张保留；第 2 页与第 7 页的三张笔记卡，以及第 4 页的标识/指示物指南，也因具有完整卡框而收录。

## 图像规格与索引

- 特工卡：`954 x 553 px`，横向，200 DPI。
- 规则卡及其他纵向卡：`556 x 960 px`，纵向，200 DPI。
- `manifest.json` 记录每张卡的稳定本地 ID、类别、源页、页内顺序、像素/PDF/归一化裁切坐标、KTDash 关联 ID 与全文核对状态。
