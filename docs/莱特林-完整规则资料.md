**中文全文**

体格不大的莱特林人们行动迅捷，能依靠自己的速
度和机敏追上或避开敌人。
在每一名敌方特工的激活后，下一名特工激活前，
一名己方莱特林特工（牛格林，欧格林和潜行客除
外）可以进行一次无消耗的冲刺行动，但不能在一
名敌方特工的 3" 内结束那次移动，除非在那次移动
