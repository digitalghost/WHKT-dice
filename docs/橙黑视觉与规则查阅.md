# 橙黑视觉与规则查阅

2026-09-23，按用户反馈在轻量记录流程上调整；不修改投掷计算逻辑。

## 视觉与交互

- 参考 https://ktdash.app/ 的近黑背景（#0F0F0F）、焦橙主色（#C54C21）、浅色文字与窄体标题。应用沿用项目已含授权文件的 Teko 字体作为英文标题，中文采用系统无衬线，避免窄体影响中文阅读。
- 首页增加战场图；队伍信息使用对应阵营图片。角色列表改为编号、名称、武器和可点击耐伤的平面行，不再一层层套卡片。
- 常用按钮视觉高度约 36dp，触控范围保留 44dp；普通入口使用文字链接。
- `RecordUi` 只维护一个真实 Dialog 窗口，内部页面带返回路径。打开详情替换面板内容，返回恢复上一页及其待选状态；关闭则关闭整个面板。未保存选择不会自动提交。
- 原投掷页的装饰金属边框改为黑灰骰盘与橙色点缀，顶部返回入口保留。

## 武器关键词

点投掷页的武器规则速查：有已选武器时，顶部显示武器名、保留具体数值的关键词及已有描述；全部规则列表用 ◆ 与底色高亮相关条目。关键穿刺映射到合并的穿刺说明，兼容平衡/均衡、眩晕/晕眩等别名。毒素、剧毒、中毒等阵营关键词也在顶部显示。

自由投掷不高亮；加载不关联武器的历史记录时清空高亮。未收录关键词明确提示查原卡，不编造描述。规则显示不自动改变骰子参数或结算。

## 对局中查看规则

- 点击队伍的“阵营规则”：阵营文字概要及 13 张完整阵营原卡，包含战团战术、毒素、韧性、钻地、隧道等。
- 点击角色名称：专属能力、AP 费用（如有）、适用阵营能力，以及完整角色数据卡。
- 对另有能力卡的角色，提供独立原卡入口：突击仲裁者军士、仲裁者军士、歼灭者狙击手、恶瘟投放者，共 4 张。
- 原卡支持缩放/拖动，页面只读，查阅不改变对局。
